# Stages 16–19 — Clipboard, Mirror, Focus, Focus Timer

| Area | Source of truth | Limits |
| --- | --- | --- |
| Clipboard | `RealClipboardService` reads `NSPasteboard.changeCount` every 0.5 s (no public change notification) and reads contents only when it moves. `ClipboardModel` owns history. | Sensitive-content exclusion is best effort: `org.nspasteboard` concealed/transient/auto-generated types and known password-manager apps (by frontmost app at copy time). macOS does not label sensitive data. |
| Mirror | `RealCameraService`: one preview-only `AVCaptureSession` (no outputs) that exists only while the preview is open. `start`/`stopRunning` run on a serial queue. | The system camera indicator follows the session; it turns off once `stopRunning` completes. |
| macOS Focus | `INFocusStatusCenter` (`isFocused` only), re-read every 4 s once authorized; there is no change notification on macOS. | macOS answers only apps signed with the Communication Notifications capability (`com.apple.developer.usernotifications.communication`). Without it the authorization request is never answered and `isFocused` reads a constant `false` (verified with a signed probe on macOS 27). Personal development teams cannot enable that capability (Xcode: "Personal development teams … do not support the Communication Notifications capability"), so this build reports Focus as unavailable rather than polling a value that never changes. The Focus name is never available; apps cannot switch Focus (the optional timer coupling runs user-chosen Shortcuts). |
| Focus Timer | `PomodoroModel` + pure `PomodoroEngine`; state and session records in `Application Support/Notchium/FocusTimer.json`. | — |

Flow: service → feature model → typed `NotchNotification` → `ActivityCoordinator` → shell. No new event bus.

## Decisions

- **Clipboard lives in the Shelf page.** The navigation order is Home · Music · Calendar · Focus Timer · Audio · Shelf, so Clipboard is the Shelf page's second section: the page title is a two-item switch (Shelf / Clipboard). Rows are one line (icon or thumbnail, preview, age); click copies back; ↑/↓, Return and Delete work in the list. History defaults to 50 items and 30 days; up to 10 pins are never evicted. Images are stored downsampled (2048 px long edge) with a 96 px thumbnail; only thumbnails are held in memory. Ordinary ⌘C never animates the notch; a copy from Notchium confirms inline on its row.
- **Stage 23 privacy and access.** Production capture is independently enabled in Settings and defaults off; disabling it stops observation and retains accepted history. Rows have native copy actions, selected semantics and Space support. Index metadata, text, paths, thumbnails and image assets are encrypted with AES-GCM and a local, non-synchronizing Keychain key. Migration commits encrypted files before deleting legacy copies. Locked or unreadable storage preserves disk data, stops disk mutation and warns that recent changes may not be saved. Unlock/reopen is the conservative recovery path; a missing key cannot decrypt history. Sensitivity detection remains best effort.
- **Mirror is a header utility** (Caffeine · Mirror · Reminder · Settings · Close). The preview opens inside the expanded shell: the page yields (fades, never unmounts) and the preview grows downward from the header through a mask (`NotchDownwardReveal`). Collapsing the notch, closing, or sleep stops capture immediately. A preview closed while the camera is starting releases it as soon as it starts. Mirrored by default; the chosen camera is remembered; a disconnected camera falls back to the next one.
- **Focus quiets Notchium, not macOS.** One compact activity (`focus.mode`, moon glyph, indigo tint) announces changes; the launch state is not announced. With "Reduce interruptions" (default on), `ActivityPriorityPolicy.isQuietedDuringFocus` drops device connections, charging/unplugged, 60/30-minute reminders and screenshots. Critical battery, 5-minute reminders, timer completion, transfers, volume and the user's own actions (Shelf drops, Quick Actions, reminders) still present.
- **Paused content leaves the collapsed notch after one shared interval** (`ActivityPriorityPolicy.pausedPresentationExpiry`, 250 ms): Music's flanks use it as their audio-silence expiry and a paused timer (Focus or either break) uses it before leaving. Hiding is presentation only; resuming restores the same activity at once.
- **Fresh opening page.** The existing Media resolver wins first (local playback and existing Music alerts; remote Spotify Connect playback keeps its Home default). Otherwise a running Focus/Short Break/Long Break opens Focus Timer, as does a timer paused less than `NotchPageModel.pomodoroPausedPageGrace` (30 seconds). `PomodoroModel.pauseInstant` is the single process-local monotonic pause instant; opening evaluates its deadline without scheduling a grace task. At the deadline Home returns. Restored paused timers do not start a new grace. Once open, page selection stays owned by that expansion session.
- **Timer.** 30 / 5 / 15, long break after the fourth Focus. Truth is the deadline; the view ticks once per second only while visible, and the only scheduled work is one sleep to the next deadline (plus wake and clock-change refreshes). Completing a phase leaves the next phase ready; clicking Skip or Skip Break advances and immediately starts the next timer in one persisted transition. Every break and Focus session still starts through user input. Sleep or relaunch catch-up completes only the stage already running, so time away never starts an unstarted phase. Completions caught up after sleep or relaunch (older than 2 minutes) update history without an announcement.
- **Timer controls.** Ready Focus: + 5 mins / Start Focus. Ready break: + 5 mins / Start Break / Skip. Running Focus: Pause. Running break: Pause / Skip Break. Paused Focus: Take Break / Resume / End Focus, with Resume centered under the timer. Paused break: Resume / Start Focus. Skip on an upcoming break and Skip Break on a running break immediately start Focus; skipping a long break also resets the cycle. A late skip click completes the expired phase and starts its successor without skipping that successor or presenting stale ready-stage controls. Take Break records the interrupted focus and readies its break; Start Focus from a paused break skips it and immediately starts the next focus. End Focus records the interruption and resets the cycle. Each + 5 mins extends only the upcoming phase and survives relaunch without changing defaults. Settings offers a long break every 1–8 focus sessions (default 4), persisted with the durations; cadence changes apply at the next focus transition without changing an active deadline. Restore Timer Defaults resets durations and cadence.
- **Timer completion banner.** A fresh Focus, Short Break or Long Break completion uses the existing downward notification reveal and Calendar width, with a 104 pt content area below the hardware notch. It is a dismissible transient with a fixed 20-second lifetime, including while hovered or hidden behind the full notch. Starting/skipping the next phase, resetting the timer, dismissal, or stopping the timer removes it early. Higher-priority notifications can interrupt it and restore it within the original deadline without replaying sound. The next phase stays ready: Focus shows + 5 mins / Start Focus; either break shows + 5 mins / Start Break / Skip. Page and banner share `PomodoroControlsView`; the banner centers Start Focus or Start Break independently of its secondary buttons. + 5 mins updates the upcoming phase duration without extending the banner deadline. Hovering the banner body does not open the full shell. The title opens the Focus Timer page; the normal notch activation area still expands normally. An already-open page stays selected and hides the banner until the shell collapses. Escape, X and the existing upward background drag dismiss only the completion. Old catch-up completions remain silent and do not create a banner.
- **Completion sounds.** Settings offers None, Chime (Glass), Bell (Ping), Soft Tap (Tink), Digital (Morse), and Celebration (Hero), with a Preview button. These are native macOS sounds played locally through an injected `PomodoroSoundPlaying` adapter, without overlapping previews. The adapter reads the system recordings into memory, applies 8× input gain (about +18 dB) with smooth peak limiting to 99% of full scale, and plays through an output-only `AVAudioEngine` at full app volume. Short recordings repeat in full with 180 ms silent gaps until the sequence lasts at least three seconds; recordings already three seconds or longer retain their duration. Repetition preserves pitch and avoids stretching brief tones such as Bell. Previews use the same boosted, extended audio. This makes alerts more audible over music without changing the Mac's output volume or other apps; audible volume still follows the current output device and system volume. The engine stops after playback or explicit cancellation; a full-volume `NSSound` fallback preserves the original alert if decoding or engine startup fails. Selection persists in UserDefaults; the previous sound toggle migrates to Glass when enabled and None otherwise. One sequence plays when a fresh Focus or break ends. Previews do not change timer/history; muted and stale completions do not play. The choices cover chime, bell, soft, digital, and success categories offered by [PomodoroTimers](https://pomodorotimers.com/) and [Pomodoro Online](https://pomodoroonline.org/clock). No third-party recordings are bundled.
- **History is derived from session records only** (start, end, focused segments, completed, cycle index). Today, the 30-day bars, streak and lifetime totals are computed on demand in the local calendar. Hovering a day’s bar adds a faint glowing border and shows its total focus duration in a small pointer-following peek, including zero-focus days, without adding a row or changing chart layout. Leaving the Focus page or closing the notch resets History to the main timer view for the next visit. Focus that crosses midnight is split across days; a completed session counts on its end day. Interrupted sessions (skip/end) count their focused time but not sessions or streak; under a minute is discarded.
- **Timer and Music.** The timer is a persistent baseline (`focusTimer`, medium) like a transfer. With "Timer" (default) and Music visibly playing, one compact activity shows artwork + countdown on the left and Music's waveform on the right, and Music is not repeated as a chip. With "Music", the timer ranks at Music's level (`focusTimerBesideMusic`): visibly playing Music keeps the notch and the timer becomes a progress-ring chip: it starts black and fills white with the elapsed share of the phase; paused Music (no flanks) never hides the timer. Changing the preference re-ranks the same activity identity; the timer is untouched. Transients (volume, screenshot, Calendar) interrupt and return to the same activity.
