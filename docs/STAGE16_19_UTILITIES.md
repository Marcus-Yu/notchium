# Stages 16–19 — Clipboard, Mirror, Focus, Focus Timer

| Area | Source of truth | Limits |
| --- | --- | --- |
| Clipboard | `RealClipboardService` reads `NSPasteboard.changeCount` every 0.5 s (no public change notification) and reads contents only when it moves. `ClipboardModel` owns history. | Sensitive-content exclusion is best effort: `org.nspasteboard` concealed/transient/auto-generated types and known password-manager apps (by frontmost app at copy time). macOS does not label sensitive data. |
| Mirror | `RealCameraService`: one preview-only `AVCaptureSession` (no outputs) that exists only while the preview is open. `start`/`stopRunning` run on a serial queue. | The system camera indicator follows the session; it turns off once `stopRunning` completes. |
| macOS Focus | `INFocusStatusCenter` (`isFocused` only), re-read every 4 s once authorized; there is no change notification on macOS. | macOS answers only apps signed with the Communication Notifications capability (`com.apple.developer.usernotifications.communication`). Without it the authorization request is never answered and `isFocused` reads a constant `false` (verified with a signed probe on macOS 27). Personal development teams cannot enable that capability (Xcode: "Personal development teams … do not support the Communication Notifications capability"), so this build reports Focus as unavailable rather than polling a value that never changes. The Focus name is never available; apps cannot switch Focus (the optional timer coupling runs user-chosen Shortcuts). |
| Focus Timer | `PomodoroModel` + pure `PomodoroEngine`; state and session records in `Application Support/Notchium/FocusTimer.json`. | — |

Flow: service → feature model → typed `NotchNotification` → `ActivityCoordinator` → shell. No new event bus.

## Decisions

- **Clipboard lives in the Shelf page.** The navigation order is Home · Music · Calendar · Focus Timer · Audio · Shelf, so Clipboard is the Shelf page's second section: the page title is a two-item switch (Shelf / Clipboard). Rows are one line (icon or thumbnail, preview, age); click copies back; ↑/↓, Return and Delete work in the list. History defaults to 50 items and 30 days; up to 10 pins are never evicted. Images are stored downsampled (2048 px long edge) with a 96 px thumbnail; only thumbnails are held in memory. Ordinary ⌘C never animates the notch; a copy from Notchium confirms inline on its row.
- **Mirror is a header utility** (Caffeine · Mirror · Reminder · Settings · Close). The preview opens inside the expanded shell: the page yields (fades, never unmounts) and the preview grows downward from the header through a mask (`NotchDownwardReveal`). Collapsing the notch, closing, or sleep stops capture immediately. A preview closed while the camera is starting releases it as soon as it starts. Mirrored by default; the chosen camera is remembered; a disconnected camera falls back to the next one.
- **Focus quiets Notchium, not macOS.** One compact activity (`focus.mode`, moon glyph, indigo tint) announces changes; the launch state is not announced. With "Reduce interruptions" (default on), `ActivityPriorityPolicy.isQuietedDuringFocus` drops device connections, charging/unplugged, 60/30-minute reminders and screenshots. Critical battery, 5-minute reminders, timer completion, transfers, volume and the user's own actions (Shelf drops, Quick Actions, reminders) still present.
- **Paused content leaves the collapsed notch after one shared interval** (`ActivityPriorityPolicy.pausedPresentationExpiry`, 250 ms): Music's flanks use it as their audio-silence expiry and a paused timer (Focus or either break) uses it before leaving. Hiding is presentation only; resuming restores the same activity at once.
- **Fresh opening page.** The existing Media resolver wins first (local playback and existing Music alerts; remote Spotify Connect playback keeps its Home default). Otherwise a running Focus/Short Break/Long Break opens Focus Timer, as does a timer paused less than `NotchPageModel.pomodoroPausedPageGrace` (30 seconds). `PomodoroModel.pauseInstant` is the single process-local monotonic pause instant; opening evaluates its deadline without scheduling a grace task. At the deadline Home returns. Restored paused timers do not start a new grace. Once open, page selection stays owned by that expansion session.
- **Timer.** 30 / 5 / 15, long break after the fourth Focus. Truth is the deadline; the view ticks once per second only while visible, and the only scheduled work is one sleep to the next deadline (plus wake and clock-change refreshes). Focus completion starts the break at the exact deadline; a finished break leaves the next Focus ready (never auto-started), so time away is not recorded as focus. Completions caught up after sleep or relaunch (older than 2 minutes) update history without an announcement.
- **History is derived from session records only** (start, end, focused segments, completed, cycle index). Today, the 30-day bars, streak and lifetime totals are computed on demand in the local calendar; focus that crosses midnight is split across days; a completed session counts on its end day. Interrupted sessions (skip/end) count their focused time but not sessions or streak; under a minute is discarded.
- **Timer and Music.** The timer is a persistent baseline (`focusTimer`, medium) like a transfer. With "Timer" (default) and Music visibly playing, one compact activity shows artwork + countdown on the left and Music's waveform on the right, and Music is not repeated as a chip. With "Music", the timer ranks at Music's level (`focusTimerBesideMusic`): visibly playing Music keeps the notch and the timer becomes a countdown-ring chip; paused Music (no flanks) never hides the timer. Changing the preference re-ranks the same activity identity; the timer is untouched. Transients (volume, screenshot, Calendar) interrupt and return to the same activity.
