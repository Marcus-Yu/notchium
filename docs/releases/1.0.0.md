# Notchium 1.0.0

Media, everyday tools, and live activities at your Mac's notch.

Highlights: Spotify media controls, Calendar and quick reminders, Shelf and
Clipboard history, Pomodoro, Mirror, audio controls, Home shortcuts, and
download/screenshot activities.

**Requirements:** macOS 26.0 or later; Apple Silicon (arm64). Intel is not supported.

**Install:** Download `{{ARTIFACT}}`, open it, and drag Notchium to Applications.
For a ZIP, unzip it first. Eject the disk image and launch from Applications.

**First launch:** This zero-cost release has no Developer ID signature or Apple
notarization. Its ad-hoc signature provides no trusted developer identity. If
macOS blocks it, try opening once, then go to **System Settings → Privacy & Security
→ Security → Open Anyway** and confirm **Open**. See
[Apple's instructions](https://support.apple.com/102445).
This is the documented supported flow; fresh-account acceptance of this candidate
is still pending. Managed Macs may prevent exceptions. Do not change security policy
or remove quarantine to force a launch.

**Setup:** New users complete the fifteen-item permission/setup wizard before
normal use. It requests available OS authorizations individually and explains
requirements that cannot be pregranted, including Core Audio and per-item Keychain
access. Clipboard monitoring requires a separate explicit choice. Completed setup
persists; Settings → Permissions reviews current access after an update or revocation.

**Limitations:** Focus is unavailable because the required entitlement cannot be
provisioned through the current development team. Closed-lid keep-awake is
unavailable because its privileged helper requires trusted signing; ordinary
Caffeine works. Spotify uses the installed Mac app through local Automation;
no client ID, developer account, or OAuth login is needed. Queue and remote Spotify
Connect selection are unavailable. Ad-hoc updates can require OS permission or
Keychain approval again. Clipboard recovery authenticates old history before
create-only migration of the same key; inaccessible history is preserved.

**Update/uninstall:** Quit before replacing the app in Applications. Keep app data
and Keychain items when updating. Trashing the app leaves preferences, bookmarks,
setup progress, Pomodoro and encrypted Clipboard history for reinstall. See the
[README](https://github.com/Marcus-Yu/notchium#updating-and-removing-notchium)
for deliberate data removal and permission recovery. Real same-identity upgrade
and Keychain acceptance are still pending for this candidate.
