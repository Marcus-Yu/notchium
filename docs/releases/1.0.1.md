# Notchium 1.0.1 — Spotify setup recovery

Version 1.0.1, build 3. Requires macOS 26+ and Apple Silicon.

Spotify setup now uses macOS’s explicit Automation authorization operation. Opening
Spotify and checking authorization have bounded UI waits. If a native consent dialog
is still pending, it remains available to answer; elapsed time never grants permission.
Denied access points to System Settings → Privacy & Security → Automation.

The fifteen-item first-launch wizard includes **Continue Without Spotify**. Choosing
it records a Spotify exception and permits Final Review once all other requirements
are satisfied. Local controls require actual macOS authorization. Retry in Settings →
Permissions later. Completed onboarding stays complete across relaunches and updates.

For testers replacing 1.0.0: quit Notchium, open `{{ARTIFACT}}`, drag Notchium to
Applications, and confirm Replace. Eject the image and open the app from Applications.
Keep Application Support, preferences, Shelf bookmarks and the existing Clipboard
Keychain item. No data reset or reinstall cleanup is needed. Ad-hoc signing can require
macOS or Keychain reauthorization; do not delete an existing encryption key.

There is no automatic updater. A GitHub source push does not update installed apps.
This build is ad-hoc signed and unnotarized. If blocked, use Apple’s supported
[Open Anyway procedure](https://support.apple.com/102445). No security-policy or
quarantine changes are needed or recommended.

Fresh-account native consent, exact packaged Finish Setup/Open Notchium, and existing
data restoration remain acceptance gates until observed on an isolated account or Mac.
A local preview is for validation and must not be published as a qualified release.
