# Notchium 1.0.1

Notchium brings Spotify controls, Calendar, Pomodoro, Shelf, Clipboard history,
and a Teleprompter with fixed-speed and on-device voice-following modes to your Mac's notch.

**Install on Apple Silicon with macOS 26 or later.** Download `{{ARTIFACT}}` from
the assets below. Open the disk image, drag Notchium into Applications, eject the
image, and launch Notchium from Applications. For a ZIP asset, unzip it and move
the app to Applications.

The app is ad-hoc signed and unnotarized. If macOS blocks it, try opening it once,
then go to **System Settings → Privacy & Security → Security → Open Anyway** and
confirm **Open**. Managed Macs may restrict this option. See [Apple's instructions](https://support.apple.com/102445).

Choose **Finish Setup** and **Open Notchium** to reach the notch. You can skip all
permissions and enable them individually later under **Settings → Permissions**.
Clipboard History stays off until you enable it. Spotify controls use the installed
Spotify app and macOS Automation permission.

## Permission and lifecycle fixes

The free closed-lid helper uses a separate registration from the Xcode build.
Identical copies of the release can use the registered helper from different
accounts and install locations. Turn Caffeine on to request approval in Login
Items & Extensions if needed. With the helper active, the Mac can keep
running with its lid closed while the built-in display is off.

Opening Mirror from Teleprompter restores the standard notch size for the
camera preview. Closing Mirror restores the larger Teleprompter layout.

Spotify setup now uses macOS’s explicit Automation authorization operation. Opening
Spotify and checking authorization have bounded UI waits. If a native consent dialog
is still pending, it remains available to answer; elapsed time never grants permission.
Denied access points to System Settings → Privacy & Security → Automation.

All fifteen permission steps are optional. **Finish Setup** works without granting
permissions, choosing a screenshot folder, selecting a Clipboard option, or reviewing
exceptions. Skipping Clipboard keeps monitoring off. Missing or denied access retains
its actual status and can be enabled later in Settings → Permissions.

**Continue Without Spotify** remains available as a review choice. Local Spotify
controls require actual macOS authorization. Completed onboarding stays complete
across relaunches and updates.

The Spotify waveform now recovers after a failed initial recording-permission
attempt when you return from the permission dialog or System Settings, even if
Spotify keeps playing continuously. Healthy capture is preserved, and audio is
still analyzed only in memory.

Adjusting the Audio page's own volume or mute controls keeps feedback inline.
Hardware volume keys still show the volume HUD, including while using the Audio page.
Camera dismissal now commits the shell's closing state before releasing the preview,
so teardown cannot overwrite a newer opening with the older close operation.

Calendar now rechecks access when you open its notch page or return to Calendar
Settings, including when the notch does not activate the app. Add Events Only
access offers Request Full Access instead of being treated as denial. Newly
granted access refreshes the service's EventKit store before loading calendars,
and temporarily empty results no longer save an initial choice to monitor nothing.
Check Again remains available after denial without repeating a denied system prompt.

The notch also retries display discovery and restores its panels after sleep,
including when displays reconnect after the initial wake notification. Recovery
stops after a short settling window and cancels on another sleep or shutdown.

For testers replacing 1.0.0: quit Notchium, open `{{ARTIFACT}}`, drag Notchium to
Applications, and confirm Replace. Eject the image and open the app from Applications.
Keep Application Support, preferences, Shelf bookmarks and the existing Clipboard
Keychain item. No data reset or reinstall cleanup is needed. Ad-hoc signing can require
macOS or Keychain reauthorization; do not delete an existing encryption key.
