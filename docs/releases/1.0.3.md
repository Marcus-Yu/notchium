# Notchium 1.0.3

The notch begins closing **180 ms** after your pointer leaves it when you opened
it by hovering. Moving the pointer back within that time cancels the close. Click
the notch to pin it open.

**Apple Silicon and macOS 26 or later.** Download `{{ARTIFACT}}` below. Quit Notchium,
open the disk image, drag Notchium to Applications, and choose Replace if asked.
Use the same installation location when replacing a copy that registered the
Caffeine helper. Eject the disk image and open Notchium from Applications.

This is an ad-hoc signed, unnotarized prerelease. macOS can ask you to approve
the new build and to grant it access to your existing Clipboard Keychain item.
You can choose **Always Allow** in the Keychain prompt to remember that approval
for this installed build. Your settings and encrypted history stay in place.
See [Apple's instructions for opening an app manually](https://support.apple.com/102445).

`{{ARTIFACT}}` is {{SIZE_BYTES}} bytes. SHA-256 `{{SHA256}}`.
Built from `{{COMMIT}}`, version 1.0.3, build 7.

If you use Caffeine’s closed-lid feature, turn it off and choose **Settings →
Caffeine → Remove Closed-Lid Helper** in the old copy before quitting. In the
new copy, turn Caffeine on and approve the helper in **System Settings →
General → Login Items & Extensions** if macOS asks. Update every copy used on
the same Mac so it matches the helper’s registered build.
